# Layered Human 4.0.12

This transition update moves routine app and model updates to
`downloads.layeredhuman.com`, backed by Cloudflare R2. Existing installations
receive this one update through GitHub; subsequent update checks and downloads
use Cloudflare.

- Reuse unchanged application files and verified model chunks. Only missing or
  changed chunks are downloaded.
- Assemble and verify the complete next version before activating it on restart.
  Files removed from a release are absent from that new version.
- Retain the previous working version and the original launcher's recovery
  behavior. Notes, progress, settings, and personal model-library overrides stay
  outside the managed application snapshot.
- Build this transition from the existing verified application packages without
  rebuilding the large installers or changing the approved models.

The original Windows launcher remains installed because it starts and supervises
managed versions. It does not perform routine network update checks once the
updated application is running.

Fresh-install download helpers may install the existing 4.0.11 package first;
the application then receives this transition update. Model-only releases still
use a new numeric patch version, while unchanged runtime files are reused.
