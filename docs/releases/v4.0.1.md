# Anatomy Explorer v4.0.1

- Fixes a macOS crash when selecting entries in the 3D Models catalog. Model
  controls now keep their dropdown rows in place instead of removing and
  rebuilding them during selection, avoiding the failing Qt accessibility path.
- Includes the same models, lessons and interface as v4.0.0.

Existing users can install this fix through the app's updater. Study progress,
notes and settings remain in user storage. Windows and Apple-silicon macOS
installers are also supplied; use the download and assembly helpers described
in `INSTALL-DOWNLOADS.md` when installing from the release downloads.
