# Layered Human v4.0.9

Anatomy Explorer now opens as **Layered Human**, with the Specimen interface:
a side navigation rail, six dark gallery walls, Literata and Fira Sans type,
numbered anatomy labels, and a depth rule beside the live atlas.

- Search anatomy and study content from the header. Visible matches can be
  selected on the body; choosing a result closes search and keeps the selection.
- Browse course units as illustrated vitrines, then open their lessons beside
  the anatomy. Histology opens as a continuous catalogue with a selected slide
  preview. Practice uses the existing quiz and spaced-review engine.
- Keep the renderer and model-loading work from v4.0.9-next, including prepared
  geometry and cluster stores. The GPU page store now participates in model
  loading and falls back to ordinary preparation if an entry cannot be used.
- Preserve the existing source-provenance removals. The website uses exposed
  anatomy captures and permitted film and tissue images. There is no skin or
  hair exterior added to the atlas.
- Existing installer names, updater identifiers and saved-preference namespaces
  remain compatible with Anatomy Explorer installations.

The selected static website and its build script are included under
`docs/design/2026-10-14-layered-human/site`. Alternative prototypes remain in the
original UI/Website branch.
