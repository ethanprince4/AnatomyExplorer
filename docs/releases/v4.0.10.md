# Layered Human v4.0.10

This release completes the native Specimen interface review across the atlas,
lessons, model library, radiology and histology.

- A continuous gallery background, compact side navigation, floating controls
  and a centered, responsive dissection rule replace the mismatched panels.
- Numbered labels use consistent gold markers and outside caption rails.
  Cutaway labels anchor to visible tissue; radiology preserves authored label
  order and restores the anatomy selected for the case.
- Lessons keep their own cutaway and reader layout. Returning through the
  sidebar opens the lesson library, while Back retains navigation history.
  Course grids stay stable during resizing, with clearer lesson spacing.
  The reader stays wide enough for recall controls on laptop displays, and
  lecture chapters are visible on first entry.
- Model previews cover the full catalogue, including intestinal wall models.
  Named stored views sit beneath the right-hand instruments. Section controls
  and selected-part descriptions no longer overlap.
- Histology keeps its continuous catalogue, slimmer scrolling and clear space
  below the global header. The Details drawer has a readable background.
- Practice now clears the global header, and atlas home framing leaves space
  for the floating bottom controls on smaller displays.
- Atlas Back and Forward restore the camera, X-ray state and complete
  selection. Radiology filters expand matching groups, and histology shows
  empty-search feedback beside the results.

The existing Anatomy Explorer installer names, update channel and saved
preferences remain compatible. Windows and Apple silicon macOS downloads are
built from this release and pass the repository's installer, runtime and
platform checks before publication.
