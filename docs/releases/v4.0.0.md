# Anatomy Explorer v4.0.0

- Refreshed Porcelain interface with clearer navigation, floating controls,
  readable labels, Noto Sans typography and the new Vitruvian-circle logo.
- Expanded lessons and course organization, improved lesson navigation, ECG
  teaching diagrams, and image-focused histology and radiology study screens.
- Updated model library using the final NPZ models and their teaching controls.
  Heart lessons share one complete Heart model with topic-specific selections.
- Improved model opening and loading feedback, with no automatic part selection.
- Fixed packaged macOS resource paths and retained managed update activation and
  rollback.

Existing users can update through the app. Study progress, notes and settings
remain in user storage. Windows and Apple-silicon macOS installers are supplied;
if an installer exceeds GitHub's per-file limit, the release includes download
and assembly helpers described in `INSTALL-DOWNLOADS.md`.
