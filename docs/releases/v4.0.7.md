# Anatomy Explorer v4.0.7

**Two Mac crashes fixed.** These crashes happened only while an accessibility tool was running, such as VoiceOver,
a window manager or a password manager:

- the app could quit after a few searches in Explore;
- it could also quit when switching the lesson grouping quickly.

Lists now create their rows when they are built, so they never add rows while they are on screen.

**Back and Forward.**

- The view the app opens on is now the first place Back returns to.
- Back from an open 3D model returns to the model library instead of the atlas.
- Back and Forward show the Details page you were reading, such as Biceps brachii, instead of
  "4 structures selected".

**Saved views.**

- Saving a view under a name that already exists asks before replacing it.
- An empty name asks again instead of doing nothing.
- Opening a saved view from Lessons or another workspace switches to Explore, so you see it.

**Smaller fixes.**

- The top bar highlights Histology, Radiology or 3D Models while a slide, a case or a model is open, instead
  of Explore.
- The Radiology button no longer jumps to the last case when you are already in the case library.
- "Related lessons" on a 3D model lists its lessons instead of an empty list.
- Lesson group headers count the whole unit, such as "1/9 finished", not only the lessons the filters show.
- Histology topics count images, the same as the tissues under them.
- Esc leaves Measure mode.
- Return in a Settings box no longer opens the colour picker.
- Hide/show panels needs one press, not two, after you close one panel.
- "More tools" has a Details item to bring Details back after closing it.
- Details no longer repeats a name as its Latin subtitle, as in "Aorta / Aorta".
- The radiology self-check scrolls to the answer when you reveal it.
- A model's "More controls" no longer repeats the Cut-away and slider controls shown above it.
- The Measure button keeps its short label instead of growing to "Measure distances".
- A search with no matches keeps the search box at the top of the panel.
