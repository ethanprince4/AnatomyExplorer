# Anatomy Explorer v4.0.5

**Mac crash when opening a group in a parts list.** On some Macs, 4.0.4 closed without warning when a group was
expanded in a model's parts list (the jejunum in the model library was the usual one). It happened when another app or
VoiceOver was reading the screen at the same moment. The parts list, the atlas tree and the histology library are now
drawn by Anatomy Explorer itself instead of by Qt's tree, so the code that crashed is no longer used there; the Qt
component that crashed is also patched to check its row numbers, for the few smaller lists that still use it. The lists
look and work as before (the arrow keys open and close groups and Space ticks a row), and clicking an arrow or tick
box no longer also selects the row.

**Shorter parts lists in the model library.** Numbered copies of one structure now share a single row per kind once
there are six of them: the jejunum's 243 numbered copies, one row each in 4.0.4, now read "Lining cell nuclei 53" and
so on, one row per kind. Ticking, selecting, searching and picking in 3D act on the whole kind. Bladder
umbrella cells, scalp follicle cells and the heart's chordae are grouped the same way. Where a structure and its cut
face are separate pieces with the same name (lymph node, oesophagus, ileum, tongue, trachea, bladder, compact bone,
jejunum), they are one row, and picking either in 3D selects both, so Isolate and Hide act on the whole structure.
A few part names read better: "Hair shaft (other follicles)", "Epithelial nuclei", "Goblet cell mucin".

**Lighter model files.** The heaviest parts of 19 models (the jejunum, pancreas, neuron, cornea, tooth and others) were replaced by simplified copies: 43 parts went from 46.8 million to 11.0 million triangles, and the model files are 419 MB smaller in total (2250 MB to 1831 MB). Each copy was checked against the original at full sampling density and by eye in close-up, so the pictures do not change. The biggest savings are the neuron (163 MB to 86 MB), jejunum (223 MB to 106 MB), cornea (83 MB to 32 MB) and tooth (50 MB to 28 MB), and these models open faster.
