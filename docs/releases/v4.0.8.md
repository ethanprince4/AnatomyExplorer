# Anatomy Explorer v4.0.8

**Faster 3D models with the new renderer.** The new renderer (on by default on Mac) draws each frame faster.
The biggest gain is in cut views and on built-in graphics. These figures are milliseconds per frame, measured
on a Windows PC with the new renderer switched on; Mac figures are not measured yet.

- Cut views on Intel built-in graphics: pancreas 138 → 77 ms, tongue 183 → 98 ms.
- Turning a model on Intel built-in graphics: tongue 103 → 82 ms, colon wall 94 → 83 ms.
- On a desktop graphics card (RTX 3080): tongue 10.2 → 7.5 ms, colon wall 10.2 → 8.0 ms, pancreas 9.1 → 7.2 ms,
  pancreas in a cut view 17.0 → 11.3 ms.
- On large models, surfaces that touch each other no longer shimmer while the view is still.
- A model too large for the graphics card's memory is stored in a compact form instead. The picture looks the
  same.

**Side panels scale with the window.** The Explore, Details, quiz, practice and lesson panels used to have a
fixed width. Now they take the same share of a laptop screen as of a large monitor, and they are never wider
than before.

**Radiology.**

- Cases from MRCP, angiography, ultrasound, nuclear medicine, fluoroscopy and mammography now show the anatomy
  and findings of their scan in 3D. Before, they showed unrelated normal tissue.
- Case labels appear where they were missing, including labels on see-through anatomy.
- Cases that use a reference model find their parts again, and the whole model fits in the panel.
- Three cases still do not match their scan well:
  - hydronephrosis with cortical atrophy: the widened collecting system is hidden;
  - scoliosis: the curve is subtle;
  - the non-specific abnormal mammogram: there is no skin outline and the breast is drawn small.

**Fixes.**

- The atlas view no longer draws only part of the canvas, with noise outside a box at the lower left. This
  happened after opening some cases on scaled displays.
