# Anatomy Explorer v4.0.6

**A new, faster renderer for models on a Mac.** On a Mac, models in the model library are now drawn by a new
renderer that talks to the graphics chip through Metal. The old renderer lit every one of the millions of tiny
triangles in a heavy model. The new one first works out which triangle shows in each pixel, then lights each pixel
once. It also skips the parts of large models that are hidden behind others. Ghosted parts, cut planes and picking
work as before, and the picture is meant to look the same.

So far it has been measured only on Windows. With a desktop graphics card, the heaviest models take about 10 ms per
frame instead of 25-31 ms. On a slower, integrated graphics chip the time no longer depends on how many triangles a
model has. This is its first release on Macs.

If a model looks wrong, turn off **Settings > Display > Fast renderer for models (new)**. Models opened after that
use the standard renderer. If the new renderer cannot start on a computer, the app uses the standard one
automatically. On Windows the new renderer is off by default and can be turned on in the same place.

**Models open faster the second time.** The app now keeps a prepared copy of each model it opens in its cache
folder, so the pancreas reopens in 0.4 s instead of 7.7 s.

- The prepared copies use up to 8 GB.
- The new renderer keeps up to 4 GB more of its own data.
- The least recently used entries are removed first.

**Smoother atlas with labels on.** Rotating the atlas with labels shown takes 6 ms per frame instead of 17.5 ms.

**Faster parts lists in large models.** In models with thousands of parts, typing in the filter is about 8 times
faster and showing or hiding structures about 2.5 times faster.
