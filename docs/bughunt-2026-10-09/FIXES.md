# Fixes applied to patched copy (app/ = Contents/Resources/app)

1. **Radiology tab while on the Radiology library jumped to the last case (shown under Explore).** `main_window.py` `_studio_radiology`: return early when the radiology library is already the current page. Bug: bugs/fixed/radio1-12-*. Verified: run v-r12b.
2. **Lesson group headers counted only filtered lessons** ("Lab 1 · 1/1 finished" under the Finished filter). `ui/lessons.py` `_fill_course` / `_fill_lecture`: header done/total now computed over the whole unit. Bug: bugs/fixed/lessons1-06-*. Verified: run v-l06 shows 1/9.
3. **Hide/show side panels needed two presses after closing one panel** (first press hid the other panel). `main_window.py` `toggle_panels`: hide both only when both are visible, otherwise show both. Bug: bugs/fixed/tree1-03-*. Verified: run v-t3b.
4. **No-match search in the Explore side panel spread its widgets over the whole panel height** (search box mid-panel, hint + dropdown at the bottom). `ui/search_panel.py`: trailing `addStretch(0)` after the results list. Bug: bugs/fixed/tree1-07-no-match-*. Verified: run v-t7b.
5. **Top navigation highlighted "Explore" while a histology slide or a radiology case was open.** `main_window.py` `_update_workspace_header`: highlight Histology for the slide viewer and Radiology while a case is shown. Bug: bugs/fixed/histo1-07-*. Verified: run v-h7 (histology → radiology → explore).
6. **"Related lessons (N)" on a 3D model opened an empty lesson list** ("No lessons match these filters") because the Lab grouping hides non-course lessons. `ui/lessons.py` `show_model_lessons`: switch to the System grouping when the current grouping would hide linked lessons; `_fill` + `ui/card_list.py` `expand_all`: groups open expanded while a model scope is active. Bug: bugs/fixed/models2-8-*. Verified: run v-m8c lists both linked lessons.
7. **Return in a Settings value box opened the "Choose color" dialog** (first auto-default button). `ui/settings_dialog.py`: all buttons in the dialog are non-default; settings already apply live. Bug: bugs/fixed/settings2-06-*. Verified: run v-s26 (no modal after Return).
8. **Histology topic tree mixed units**: topic rows counted tissues while tissue rows counted images, so a parent showed "3" above a child showing "15". `ui/histology.py` `_build`: topic rows now total their images (tooltip "N images in this topic"). Bug: bugs/fixed/histo2-06-*. Verified: run v-h26c (Epithelium 65 over 11/12/13…).
9. **Back from an opened 3D model skipped the model library** (landed on the Explore atlas). The model's loading placeholder was recorded as a "3D anatomy" place. `main_window.py` `_capture_place`: don't record while a loading placeholder is current; also record center-view switches (`center.currentChanged` → `_note_place`) so Explore ↔ library ↔ model moves are places. Bug: bugs/fixed/models2-5-*. Verified: run v-m5e (history = library, model; Back → library, Forward → model).
10. **The opening Explore view was never in Back history** (Back went disabled on the first library you visited). `main_window.py` `__init__`: record the opening view as the first place (`QTimer.singleShot(0, self._note_place)`); with fix 9, switching back to Explore from a library is recorded too. Bug: bugs/fixed/views1-03-*. Verified: run v-v3c (history 3D anatomy → Lessons → 3D models; Back×2 lands on Explore).
11. **Opening a saved view from another workspace restored it invisibly** (camera changed behind Lessons; you stayed on Lessons). `main_window.py` new `open_saved_view` (switch to Explore, then `apply_view`), used by the Saved views menu and `ui/saved_views.py` manager "Open". Bug: bugs/fixed/views1-08-*. Verified: run v-v8b (from Lessons → Explore with the view applied).
12. **3D model "More controls" repeated Cut-away and Separate layers/Tissue opacity** already shown in the compact Reveal row. `ui/model_view.py` `_compact_reveal`: hide the advanced originals the compact row mirrors (as was already done for "Teased"); compact slider now uses the model's own "Separate parts/layers" title. Bug: bugs/fixed/models2-6-*. Verified: run v-m6 (screenshot; mirrored Cut-away still drives the model).
13. **Top navigation highlighted "Explore" while a 3D model was open or loading** (extends fix 5). `main_window.py` `_update_workspace_header`: model tabs and loading placeholders highlight "3D Models". Verified: run v-m6b.
14. **Radiology self-check: the revealed answer was cut off below the question** in the short notes box. `ui/radiology.py`: anchor the answer paragraph and scroll to it on "Show answer". Bug: bugs/fixed/radio2-08-self-check-*. Verified: run v-r29c (scrolled to the answer).
15. **Saving a view under an existing name silently overwrote that view; an empty name silently did nothing.** `main_window.py` `save_view_dialog`: empty name re-prompts ("a saved view needs a name"); an existing name asks "Replace it?" (No returns to the name prompt). Bugs: bugs/fixed/views2-04-*. Verified: run v-sv.
16. **CRASH (SIGSEGV) after a few successive searches in Explore** — reproducible 3/3 with `search:Biceps brachii;activate;…femur…median nerve…aorta…liver…nasion`. Crash is in Qt's Cocoa accessibility bridge (`QAccessible::updateAccessibility` ← `QAbstractItemModel::endInsertRows` ← `QListWidget.addItem`) when the results list grows while on screen with hidden reused rows. Active whenever any accessibility client is running (VoiceOver, window managers, password managers, automation). `ui/stable_rows.py` new `reserve_rows`; `ui/search_panel.py` reserves all `RESULT_LIMIT` (150) result rows at construction so refills never add rows. Bug: bugs/fixed/details1-01-*. Verified: same sequence 3/3 clean (v-cf1..3), crash reports AnatomyExplorer-2026-10-09-065814/071157/071212.ips before.
   Residual: Qt still logs "QAccessibleList::child: Invalid index" warnings for this list and for CardList lists (bugs/storm1-08-*); no crash observed from those paths, but CardList also adds rows on demand (ui/card_list.py `_row`) — same pattern, worth the same treatment if a crash ever shows up there.
17. **UX: once Details was closed there was no visible way back** (only the hide/show-panels shortcut). `ui/studio_shell.py`: "More tools" menu gains a "Details" item beside "Parts" and "Reveal controls". Bug: bugs/fixed/details1-02-*. Verified: run v-d3.
18. **Details header repeated the name as its Latin subtitle** ("Aorta" / *Aorta*). `ui/info_panel.py`: new `same_name()`; the Latin line is skipped when it only repeats the heading (structures, groups, landmarks). Bug: bugs/fixed/details1-03-* (its minor "(7)" vs "7 images" wording note left as is). Verified: run v-d5 (Aorta no repeat; Biceps keeps *Musculus biceps brachii*).

Bug: bugs/fixed/details2-3-back-*. Verified: run v-db2 (Biceps ↔ Femur both directions).
