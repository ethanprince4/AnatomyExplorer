# Selected navigation: Side rail (option 2)

The selected checkpoint 3 navigation is the Side rail, option 2. It keeps the six destinations in a compact side rail, with clear current-place state and useful Back/Forward navigation. A room can remember the current item; selecting its active destination returns to the room front page. Keep keyboard navigation and visible focus.

The current application navigation and destinations are authoritative. The old mockup data and screenshots are not runtime dependencies and are not included in this package.
