# Specimen website

The selected Specimen direction presents the body as an exhibit on a dark museum wall. Keep the body and actual renderer plates as the focus; use Literata for display and Fira Sans for interface text. The site remains a single responsive static page, with six dark wall schemes and a persistent keyboard-accessible scheme switcher.

The shipped hero begins at the first available 26% render. The control moves among available deeper views only; do not add an exterior-skin, hair or invented layer. The kidney exhibit uses actual kidney, renal corpuscle and podocyte views and this copy: “Explore the kidney, vessels and ureter, with linked views of a nephron and its microscopic structures.”

Films use the retained CC0 PA chest radiograph and the related thorax model, clearly identified as separate sources. Histology uses the retained CC0 Berkshire Community College Bioscience Image Library micrograph. Credit both sources and link directly to their Wikimedia Commons records. The removed ShareAlike image families and all derivatives are excluded from this package.

The download desk links to the published Mac DMG. Windows links to the current release landing page until the release contains the exact installer asset. The install directions must describe only what is available on that page.

Run `python site/build.py` from this directory to produce `site/dist/`. The builder checks the page and stylesheet references against the copied files.
